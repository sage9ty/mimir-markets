# Squad Cancel Market PR

This document is the PR write-up for the squad cancellation market changes.

## Summary

This change introduces squad cancellation in the market flow, so participants can cancel a formed squad before finalization.

## Changes

- Added market-level cancellation handling for formed squads.
- Exposed cancellation state to clients.
- Added tests for the cancellation flow.

## Testing

- Unit tests cover the cancellation flow and edge cases.
